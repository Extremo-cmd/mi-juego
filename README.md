## Descripción del Proyecto

Este proyecto consiste en un videojuego web desarrollado con HTML5, CSS3 y JavaScript, que utiliza la Canvas API para generar gráficos en 2D de manera dinámica.

El objetivo principal es demostrar el uso del elemento `<canvas>` mediante la creación de un videojuego interactivo en el que aparecen múltiples objetos (zombies) que se mueven en distintas direcciones y deben ser eliminados mediante el uso del mouse.

El juego incluye elementos como movimiento aleatorio, detección de colisiones con el cursor, eliminación de objetos, incremento de dificultad por niveles y sistema de puntuación (Score y High Score).

La interfaz presenta un diseño moderno con Bootstrap, además de un fondo gráfico y un cursor personalizado que mejora la experiencia del usuario.
